# 🎬 Movie Tracker

**Movie Tracker** — это веб-приложение для поиска, просмотра и добавления фильмов в личный список.
Проект находится **в процессе разработки** и постепенно дополняется новыми страницами и функциями.

🔗 **Live Demo:** https://karinakit.github.io/Movie-Tracker/

---

## 📌 О проекте

Movie Tracker создаётся как pet-проект для практики **HTML, CSS, JavaScript, TypeScript, Vite и Supabase**.

Основная идея проекта — сделать удобный каталог фильмов, где пользователь сможет находить интересующие его фильмы, добавлять их в свой список, открывать подробную информацию и оставлять комментарии.

---

## ✅ Уже реализовано

### 🎬 Главная страница — каталог

На главной странице реализованы:

* каталог фильмов;
* карточки фильмов;
* поиск фильмов;
* сортировка/фильтрация по жанрам;
* адаптивная верстка;
* интерактивные элементы и hover-эффекты;
* возможность добавить фильм в **Playlist**.

### 🔎 Поиск

Реализован поиск фильмов по каталогу.

### 🎭 Жанры

Добавлена фильтрация фильмов по жанрам.

> В дальнейшем фильтрация по жанрам будет доработана визуально и функционально, чтобы пользоваться ей было удобнее.

### 🔐 Регистрация и авторизация

Для работы с пользователями используется **Supabase Auth**.

Реализованы:

* регистрация пользователя;
* вход в аккаунт;
* проверка email;
* проверка пароля;
* проверка подтверждения пароля при регистрации;
* вывод сообщений об ошибках;
* сохранение пользователей в Supabase;
* выход из аккаунта.

### ⚡ Vite

Проект работает через **Vite**, который используется для разработки и сборки приложения.

### 📋 Playlist

Будет отдельная страница со списком фильмов, которые пользователь хочет посмотреть.

На главной странице пользователь сможет нажать кнопку:

**«Добавить в Playlist»**

После этого выбранный фильм будет добавляться на страницу Playlist.

На странице будут отображаться фильмы, которые пользователь добавил для просмотра позже.
